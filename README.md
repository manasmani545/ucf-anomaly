# Weakly Supervised Temporal Action Localization

Temporal action localization using video-level labels, multiple-instance learning,
and temporal context modeling. Prepared as a foundation for video anomaly detection.

## Pipeline

Raw videos -> clip sampling -> feature extraction -> cached features ->
temporal model -> MIL aggregation -> temporal localization -> evaluation.

Phase 1: completed planning.
